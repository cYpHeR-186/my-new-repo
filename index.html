Help & Documentation

Welcome to GitHub Forge — your complete GitHub management toolkit.

Dashboard

Shows an overview of your repositories, file count, user info, and recent activity.

Repository Manager

Search and browse all your repositories. Filter by branch or visibility. Change visibility and branch directly.

Deploy Center

Upload or update any file. Supports all file types. HTML files get GitHub Pages with a loading animation.

File Explorer

Browse files and folders with a tree view. Click any file to view its content.

Rename Repository

Change the name of any repository. The new name must be unique.

Delete Manager

Delete individual files or entire repositories with double-confirmation safety.

Analytics

View repository statistics: stars, forks, watchers, creation date, and last update.

Activity Logs

View a timeline of your actions — deploys, deletions, renames, and more.

Language Support

Switch between English, বাংলা (Bengali), and Русский (Russian).

All features work with your real GitHub data. Everything is production-ready.
